ID and Name:
UC-1 Register Account
Created By:
Nguyen Quoc An
Date Created:
01/10/2020
Primary Actor:
User
Secondary Actors:
News System
Description:
To order the user needs to go to the registration page.
Fill in full information about the account (Full name, email or phone   number phone, password, date of birth, gender, address).
Successful registration will return to dashboard
If registration is unsuccessful, it will ask to fill in the correct format.
Trigger:
Adding personal data.
Preconditions:
PRE-1. The user needs to have internet access. 
Post conditions:
POST-1. The user has now the rule â€œMemberâ€ and can manage his account.
POST-2. This user is also now logged in.
Normal Flow:
Register account
If he doesn't have an account, he can create a new one. There are two ways to do that.
The first is that the user enters email and password to create a new account.
Or registered user account.
1. Open the registration page.
2. Enter full data to post
3. Send the registration data to the server.
4. Create users.
5. When redirected to the control panel successful.
Alternative Flows:
None
Exceptions:
 Should be not able to register with duplicate email.
 Should be not able to register with missing fields.
 Should be not able to register with duplicate username 

Business Rules:
Password must conform to the configured of PNS (Posting News System) password strength policy (such as alphabetic and non-numeric characters of a minimum length).
Email must be unique and conform to the configured PNS manage policy (such as email: chauhuudang1702@gmail.com already created then not use email again. Must be use different email).
Priority:
High
Other Information:
None

Admin is responsible for checking customer information, checking products added, editing, or deleting by employees, Admin must check product images, product prices before posting on the display website.
Trigger:
None
Preconditions:
PRE-1. Admin is logged into website.PRE-2. Admin browses products for employees
Postconditions:

2. Check if the newly added product has the right image, quantity, price, label before modifying

Created By:

Date Created:
01/10/2020
Primary Actor:
Staff
Secondary Actors:
Censor
Description:
Staff add product correction, moderation, and accept orders ordered by customers
Trigger:
Cancellation of an order when the customer is no longer placing an order and processing a canceled order
Preconditions:
PRE-1. Staff has logged into the website
Postconditions:
POST-2. Staff added products and waited for moderation
Normal Flow:
4.0 Cancel request to add product
1.The system will check whether the added products are moderated by admin or not
2. The system verifies that there are too many products to be added, it will cancel the request for more products.
Alternative Flows:
None
Exceptions:
4.0.E1 The poster is not eligible to cancel the post
Priority:
High
Business Rules:
Control the eligibility of a poster to make a poster's request to cancel a post.
Other Information:
Expect posters to master and use this system regularly.
